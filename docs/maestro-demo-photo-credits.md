# Demo menu photos — credits

(free licences), cropped to 800 × 600 and stored in the public `smartserve` storage bucket under
`dishes/maestro-demo/`. They show a similar dish, not the caterer's own plating. Replace them with
the caterer's photos before a real event (Menu tab › Edit dish › Photo URL).
